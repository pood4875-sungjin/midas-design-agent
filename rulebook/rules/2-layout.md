# Node 2 — 레이아웃 골격 / 진입형태

아키타입 → 화면 영역 분할 + 진입형태(풀페이지/모달/드로어) 결정.

## 공통 골격 (bootstrap §7 — 전 화면 공통)

- **GNB 상단 고정**: 로고 + 프로젝트 셀렉터 + 상단탭(프로젝트홈/계측/해석/보고서 + 도메인별 추가) + 알림(dot)/프로필. h≈64~72.
- **페이지 헤더**: 타이틀 + 메타배지(파일.gxb·상태요약) + 우측 액션("변경이력"/"편집"/primary).
- **브레드크럼 + 단면 dropdown**으로 케이스/단면 전환.
- **서브탭바**: 화면 내 관점 전환.
- **문서형 예외**: 뷰어는 GNB 버리고 전용 크롬(목차+2-up+줌).

## 진입형태 규칙 (실전 교훈 — 소스 우선)

### R-2.1: 진입형태는 소스가 정한다
- 조건: Figma 노드 있음
- 결정: 시안의 진입형태(모달/드로어/페이지) **그대로**. 추측 금지.
- 근거: 멤버관리 — PRD추측=드로어 / 실제시안=**중앙 모달**. 빗나감.
- 신뢰도: 확정

### R-2.2: PRD만일 때 진입형태 게이트
- 조건: PRD 텍스트만, 진입형태 미명시
- 결정: 후보 제시(드로어/모달/페이지) → 사용자 승인 후 확정
- 근거: 동일 교훈
- 신뢰도: 규칙(메타)

### R-2.3: 관리/초대 UI 기본형
- 조건: 패밀리 F(멤버·권한) 관리
- 결정: **중앙 모달**(w≈1000, r16, 딤 80%). 상태=섹션그룹. 헤더(타이틀+부제 중앙)/바디(입력행+섹션들)/푸터(확인).
- 근거: 멤버초대 Figma 12774:40857
- 신뢰도: 확정
