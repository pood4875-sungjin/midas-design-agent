# 화면 설명서 — 현장 요약 (통합 프로젝트 관리)

> **화면 종류**: 요약·보고서형 (Dashboard / Report) · 프로젝트 선택 전 / 서비스 홈
> **Figma**: https://www.figma.com/design/Dlwg17pNvKRubRoHP0bWVF/온사이트-제품-최종?node-id=10142-16628&m=dev

---

## 1. 언제 / 왜 쓰나
- 각 현장의 상태를 **주기적으로 요약해 보고서 형태**로 보여주는 화면.
- "지금 위험한가"(지도·리스트)보다 **"기간 동안 어땠나"** 를 정리·전달할 때.
- 읽고·공유·인쇄하는 정적 성격이 강함.

## 2. 화면 뼈대 (위 → 아래)
- **전역 유틸바** + **서비스 홈 GNB** (현재 = 현장 요약)
- **기간 / 현장 선택**: 어느 기간, 어느 현장(들)의 요약인지
- **요약 KPI 카드**: 전체 현장 수 · 위험 현장 수 · 주요 지표 등 핵심 수치
- **현장별 상태 요약**: 현장마다 상태·핵심 계측 요약 (카드 또는 표)
- **추세 차트**: 기간별 변화(시계열 → 라인 차트)
- **보고서 섹션**: 정리된 문서형 레이아웃

## 3. 규칙 (지켜야 할 것)
- **보고서는 정적·인쇄를 고려.** 화려한 인터랙션보다 가독성·정리.
- 핵심 수치(위험 현장 수 등)가 위계상 먼저.
- 상태 색·차트 색은 **디자인 토큰만**. 임의값 ❌.
- 계측 초과 단계는 그라데이션 토큰으로 강조.
- 차트 종류: 기간 추세 = 라인, 현장 비교 = 바 (데이터 성격에 맞게).

## 4. 상태(status) 처리 — 온사이트 척추
| 상태 | 의미 | 토큰 |
|---|---|---|
| 안전/정상 | 문제 없음 | `--color-safe` (green) |
| 주의·경고 | 관찰 필요 | `--color-caution` (orange) |
| 위험 | 조치 필요 | `--color-danger` (red) |
| 사이렌 | 즉시 대응 | `--color-siren` (bright red) |
| 계측 초과 단계 | 1~3차 초과 | `--grad-exceed-1~3` (그라데이션) |
