## 2. 결정축 검증 (§4.1 6축 → 7축)

판독으로 6축 모두 실사용 확인. **1개 축 추가 필요:**

| 축 | 관측된 선택지 | 규칙 씨앗 |
|----|--------------|-----------|
| 데이터표현 | 맵 / 테이블 / 아코디언 / 문서 / 차트+표 / 다이어그램+표 / 표+간트 | 아래 §3 패턴으로 세분 |
| 필터/검색 | 정렬 dropdown / 검색바 / 컬럼필터(멀티체크) / 탭 / 없음 | "대량목록 → 검색바+컬럼필터, 소량 → 정렬 dropdown만" |
| 상태표현 | **컬러 텍스트**(배지 pill 아님) / 컬러마커 / 그라데이션 / 진행바 | §5 상태 정책 |
| 페이징 | pagination / 가로스크롤 / 세로롱스크롤 / 아코디언접기 / 없음 | "표 대량 → pagination, 시간그룹 → 아코디언, 문서 → 세로스크롤" |
| 밀도 | 심플 / 디테일 | 관리·결과화면 = 디테일, 온보딩·모달 = 심플 |
| 부가상태 | 생성중(스피너) / 실패 / 미연결·미해석 명시 / 빈 | "빈칸 대신 명시 라벨" |
| **★ 편집상태 (신규)** | 조회 / 편집중 / 읽기전용(락) | §6 편집상태 정책 — 가장 강한 반복 신호 |

> **편집상태를 정식 7번째 축으로 승격.** 계측데이터·전처리 등 워크스페이스가 조회/편집중/읽기전용 3상태를 동일 레이아웃으로 토글 → 별도 화면 아니라 상태 규칙.

## 3. 데이터표현 패턴 카탈로그 (씨앗 8종)

| 패턴 | 골격 | 쓰인 화면 | 레시피 컴포넌트 |
|------|------|-----------|----------------|
| **맵 모니터링** | 전면 지도 + 플로팅 요약패널 + 하단 가로카드리스트 | 지도뷰 | 지도마커(위험도컬러), 도넛게이지, 플로팅카드, 정렬 dropdown |
| **관리 테이블** | 타이틀+우측 primary(추가) → 탭 → 테이블 → pagination | 리스트뷰, 계측데이터관리, 맞춤보고서 | 테이블, 컬러텍스트 상태, 행 hover액션/케밥, pagination |
| **다이어그램+대조표** | 좌 단면 다이어그램 + 우 설계/실측 대조 테이블 + 요약행 | 시공현장정보 | 단면도(레전드), 델타 인디케이터(부호+화살표+컬러) |
| **표+간트** | 좌 데이터그리드 + 우 간트 타임라인(스케일 토글) | 공정관리 | 간트바(상태컬러), 세그먼트토글(주/월/분기), 현재시점 라인 |
| **차트+검토표** | 헤더 상태요약 → 서브탭 → 시공단계 stepper → 좌 차트 + 우 검토표 | 최신 해석결과 | line chart(다중선+레전드), stepper, 검토 테이블 |
| **전후 대비** | 진입 요약모달 → 좌 변경사항 리스트(전→후) + 우 파라미터 | 보완설계안 | before(회색)→after(강조) 대비, 컬러 레전드칩 |
| **시간그룹 아코디언** | 연도 dropdown → 월 아코디언(건수배지) → 상태별 조건부 액션행 | 정기/현장 보고서 | 아코디언, 상태태그, 조건부 액션(AI요약/재시도) |
| **문서 뷰어** | GNB 대체 전용크롬 → 좌 목차 + 중앙 2-up 문서 + 하단 줌/페이지 툴바 | 보고서 뷰어, 현장요약(롱스크롤 변형) | 목차트리, 페이지드 문서, 줌 슬라이더 |

## 5. 상태표현 정책 (강한 일관성)

- **상태 = 컬러 텍스트** (배지 pill 아님). 표 밀도 유지·시각 노이즈 억제 목적.
- **초과 에스컬레이션**: 1차→2차→3차 = **파랑 → 주황 → 빨강**. (DESIGN-SYSTEM.md `grad-exceed-*`·`status` 정합)
- 설계 검토: OK=회색/녹, NG=주황/빨강.
- 위험도는 맵 마커 컬러로 즉시 서열화(빨강=위험 최우선).

## 7. 레이아웃 골격 공통 규칙

- **GNB 상단 고정**: 로고 + 프로젝트 셀렉터 + 상단탭(프로젝트홈/계측/해석/보고서) + 알림(dot배지)/프로필. 도메인별 메뉴 추가(현장관리 등).
- **페이지 헤더**: 타이틀 + 메타배지(파일.gxb·상태요약) + 우측 액션("변경이력"/"편집"/primary).
- **브레드크럼 + 단면 dropdown**: 단면/케이스 전환을 브레드크럼 내 dropdown으로.
- **서브탭바**: 화면 내 관점 전환(요약/변위/설계검토 등), 카운트 배지.
- **이력관리 상시**: 우상단 "변경 이력" 버튼 = CRUD 화면 공통.
- **문서형 예외**: 뷰어는 GNB 버리고 전용 크롬(목차+2-up+줌).
