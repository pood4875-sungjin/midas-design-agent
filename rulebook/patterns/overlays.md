# 패턴 카탈로그 — 오버레이 (드로어/패널 + 모달 5종)

bootstrap은 화면 위주라 오버레이 골격이 얇았음 → 멤버 2빌드로 보강.

## 진입형태 오버레이

### O1. 우측 드로어
- 골격: 딤 백드롭 + 우측 고정 패널(w≈440, shadow-drawer). 헤더(타이틀+X)/바디 스크롤/섹션.
- 쓰임: 컨텍스트 유지한 채 사이드 관리. (PRD 추측 빌드 — 소스 확인 필요)
- 주의: 진입형태는 R-2.1 소스 우선. 드로어는 소스가 드로어일 때만.

### O2. 중앙 관리 모달
- 골격: 딤 80% + 중앙 카드(w≈1000, r16). 헤더(타이틀+부제 중앙, X 우상단)/바디(입력행+섹션들)/푸터(확인 우측).
- 상태 = 섹션 그룹(태그 없이). 입력 = 토큰 멀티셀렉트+역할 dropdown+초대(dark).
- 출처: 멤버 초대 Figma 12774:40857 (확정)

## 모달 유형 (bootstrap §4 — 5종)

| 유형 | 크기 | 구조 | 규칙 |
|------|------|------|------|
| **확인 다이얼로그** | 소(~400) | 제목+설명+[취소·확인] | 파괴결과 문구 고지, confirm=primary(파괴는 danger) |
| **확인+파라미터** | 소(~390) | 제목+필수입력1+접힌 고급값+[취소·확인] | confirm을 "실행 직전 세팅"으로, 고급값 progressive disclosure |
| **설정 폼** | 중 | 제목+세그먼트탭+폼+[기본값복원·취소·확인] | 상호배제 필드 disabled 잠금, 소급미적용 사전고지 |
| **이력/조회** | 대(~1020) | 제목+탭+와이드테이블(X만) | 실패이력도 표시(무결성), 행별 파일 다운로드 |
| **경고/소프트락** | 소(~340) | 경고아이콘+제목+안내박스+[취소·확인] | 완전차단 대신 읽기전용 대안, 잠금주체(이름) 명시 |

## 실물 매핑
- `components/modal/` (backdrop·modal·--md·--lg·head/body/foot)
- 확인형 = 기본 .modal / 관리형 = .modal--lg
- 딤 = `--dim-backdrop`(R-5.4)
