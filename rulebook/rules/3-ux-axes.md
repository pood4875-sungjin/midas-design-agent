# Node 3 — UX 결정축 (7개)

fuzzy 판단을 유한 축으로 쪼갬. 축마다 "신호 → 선택" 규칙. 축 조합 = 선택된 패턴([patterns/]).

## 축 목록 + 규칙

### 1. 데이터표현
- 선택지: 맵 / 테이블 / 아코디언 / 문서 / 차트+표 / 다이어그램+표 / 표+간트 / 활동피드(잠정)
- **R-3.1**: 위치+상태 → 맵+상태리스트 (확정, 지도뷰)
- **R-3.2**: 목록+행편집 → 관리테이블 (확정, 계측데이터)
- **R-3.3**: 시간그룹(월별 등) → 아코디언 (확정, 정기보고서)
- **R-3.4**: 설계vs실측 대조 → 다이어그램+대조표 (확정, 시공현장정보)

### 2. 필터/검색
- 선택지: selection / dropdown / 검색바 / 컬럼필터(멀티체크)
- **R-3.5**: 대량목록 → 검색바+컬럼필터 / 소량 → 정렬 dropdown만 (잠정)
- **R-3.6**: 멤버추가 등 = **토큰 멀티셀렉트 입력**(칩) + Enter 확정 (확정, 초대모달)

### 3. 상태표현 → [5-tokens] 컨텍스트 규칙으로 위임
- 선택지: 컬러텍스트 / 태그 / **섹션그룹** / 그라데이션 / 진행바
- **R-3.7**: 표=컬러텍스트 / 리스트카드=태그 / 관리모달=섹션그룹 (확정, 2빌드 대조)

### 4. 페이징
- 선택지: pagination / 가로스크롤 / 세로스크롤 / 아코디언접기 / 무한(잠정)
- **R-3.8**: 표 대량 → pagination / 시간그룹 → 아코디언 / 문서 → 세로스크롤 (확정)

### 5. 밀도
- **R-3.9**: 관리·결과=디테일 / 온보딩·모달=심플 (잠정)

### 6. 부가상태
- **R-3.10**: 빈/로딩/에러/생성중 항상 정의. **빈칸 대신 명시 라벨**(미연결/미해석) (확정)
- **R-3.11**: 실패 시 변경 전 롤백 + 그 자리 재시도 (확정, 계측/보고서)

### 7. 편집상태
- 선택지: 조회 / 편집중 / 읽기전용(락)
- **R-3.12**: 동일 레이아웃, 인터랙션만 토글(드롭다운↔텍스트, 버튼 활성↔회색). 락 진입은 경고 소프트락 모달 경유 (확정, 편집중/읽기전용)

## 축 확장
새 축 필요(예: 실시간/읽음상태)면 게이트. 축은 천천히, 패턴은 자주 는다.
