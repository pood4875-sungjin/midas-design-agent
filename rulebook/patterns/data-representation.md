# 패턴 카탈로그 — 데이터표현 (8종)

각 패턴 = 골격 + 컴포넌트 레시피 + 슬롯. Node3 축조합이 여기로 매핑. 근거 = bootstrap 24화면.

## P1. 맵 모니터링
- 골격: 전면 지도 + 좌상단 플로팅 요약패널 + 하단 가로 카드리스트
- 컴포넌트: 지도마커(위험도컬러)·도넛게이지·플로팅카드·정렬 dropdown
- 슬롯: 마커.color←위험도, 카드.title←현장명
- 출처: 지도뷰 5047:26122

## P2. 관리 테이블
- 골격: 타이틀+우측 primary(추가) → 탭 → 테이블 → pagination
- 컴포넌트: 테이블·컬러텍스트 상태·행 hover액션/케밥·pagination
- 슬롯: 컬럼←필드, 상태셀←status(R-5.3 텍스트)
- 출처: 리스트뷰·계측데이터관리

## P3. 다이어그램+대조표
- 골격: 좌 단면 다이어그램 + 우 설계/실측 대조 테이블 + 요약행
- 컴포넌트: 단면도(레전드)·델타 인디케이터(부호+화살표+컬러)
- 출처: 시공현장정보 14001:154962

## P4. 표+간트
- 골격: 좌 데이터그리드 + 우 간트 타임라인(스케일 토글)
- 컴포넌트: 간트바(상태컬러)·세그먼트토글(주/월/분기)·현재시점 라인
- 출처: 공정관리 14001:165369

## P5. 차트+검토표
- 골격: 헤더 상태요약 → 서브탭 → 시공단계 stepper → 좌 차트 + 우 검토표
- 컴포넌트: line chart(다중선+레전드)·stepper·검토테이블
- 출처: 최신 해석결과 14001:185837

## P6. 전후 대비
- 골격: 진입 요약모달 → 좌 변경사항(전→후) + 우 파라미터
- 컴포넌트: before(회색)→after(강조) 대비·컬러 레전드칩
- 출처: 보완설계안 14001:190565

## P7. 시간그룹 아코디언
- 골격: 연도 dropdown → 월 아코디언(건수배지) → 상태별 조건부 액션행
- 컴포넌트: 아코디언·상태태그·조건부 액션(AI요약/재시도)
- 출처: 정기/현장 보고서

## P8. 문서 뷰어
- 골격: GNB 대체 전용크롬 → 좌 목차 + 중앙 2-up 문서 + 하단 줌/페이지
- 컴포넌트: 목차트리·페이지드 문서·줌 슬라이더
- 출처: 보고서 뷰어 / 현장요약(롱스크롤 변형)

## (잠정) P9. 활동 피드/타임라인
- 시간순 이벤트 스트림. bootstrap 미관측 — gap 테스트에서 후보로만 도출. 실물 등장 시 확정.
