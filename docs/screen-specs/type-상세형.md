# 화면 설명서 — 상세형 (Detail)

> **종류 차원 설명서** (개별 화면 아님). 이 종류의 모든 화면이 공유하는 뼈대·규칙.
> 근거: 센서 상세 · 단면 상세 · 시공 현장 정보 (실측 화면).

---

## 1. 언제 이 종류로 가나
- **한 대상**(센서 1개 / 단면 1개 / 현장 1곳)을 **깊이** 보여줄 때.
- 목록형이 "여럿 훑기"라면 상세형은 "하나 파고들기".
- 판별 질문: *"한 대상을 깊이 파고드는가?"* → 예 → 상세형.

## 2. 화면 뼈대 (슬롯)
위→아래, 좌→우. 대상에 따라 일부 슬롯만 쓴다.

| 슬롯 | 내용 | 필수 |
|---|---|---|
| **헤더** | 대상 식별(이름·코드) + 상태 + 주요 액션 버튼 | 필수 |
| **핵심 시각화** | 차트(시계열) 또는 도면/단면 다이어그램 | 권장 |
| **요약 KPI** | 핵심 수치 카드 몇 개 (최댓값·갱신시각 등) | 선택 |
| **상세 데이터** | 시점·항목별 테이블 | 권장 |
| **보조 정보 패널(우측)** | 메타·실측값·이력 요약·관련 액션 | 선택 |

## 3. 표면 (이 종류가 쓰는 컨테이너) — 종류 아님
같은 상세형이라도 상황에 따라 표면이 달라진다.
- **페이지**: 대상이 크고 오래 머무름 (단면 상세, 시공 현장 정보)
- **모달**: 목록에서 한 건 빠르게 열어볼 때 (센서 상세, 값 확인)
- **도면 캔버스**: 대상이 공간/도면일 때 (단면도, 지층 단면) — 줌·레이어 토글
- **서브 모달**: 이력 보기 · 파일 업로드 · 항목 연결

표면 선택 규칙:
```
목록에서 한 건 빠르게 확인  → 모달
독립적으로 깊이 탐색·오래 머묾 → 페이지
대상이 도면/공간            → 페이지 + 도면 캔버스
```

## 4. 상태 (state)
빈 상태 / 로딩 / 정상 / 부분데이터 모두 설계. 자주 빠지는 게 빈 상태.
- **빈 상태**: "○○가 등록되지 않았습니다" + 등록 유도 버튼 (실측 화면에 다수 존재).
- 데이터 일부 누락 시 빈 값 표기 규칙 적용.

## 5. 규칙 (지켜야 할 것)
- **위험이 먼저.** 상태 색(아래)로 위험·초과를 즉시 보이게.
- 색·간격·타이포·테두리는 **디자인 토큰만**. 임의값 ❌.
- 차트 종류: 시계열 → 라인, 항목 비교 → 바.
- 숫자·단위·날짜·빈값 표기는 라이팅 정책 따름(단위 표기, 빈값 `-`).
- 모달일 때: 배경 dim + 닫기 + 핵심만. 페이지일 때: 전체 폭 + 보조 패널 허용.

## 6. 상태(status) 색 — 온사이트 척추
| 상태 | 토큰 |
|---|---|
| 안전/정상 | `--color-safe` (green) |
| 주의·경고 | `--color-caution` (orange) |
| 위험 | `--color-danger` (red) |
| 사이렌 | `--color-siren` (bright red) |
| 계측 초과 1~3차 | `--grad-exceed-1~3` (그라데이션) |

## 7. 대표 케이스 (실측 노드)
| 케이스 | 표면 | 특징 |
|---|---|---|
| 센서 상세 | 모달 | KPI + 바차트 + 데이터 테이블 |
| 단면 상세 | 페이지 + 도면 캔버스 | 단면도 + 우측 정보패널 + 업로드/이력/연결 모달 |
| 시공 현장 정보 | 페이지 | 지층 단면 다이어그램 + 데이터 테이블 + 편집/이력 모달 |

## 8. MCP에 던질 때 (복붙용)
```
맥락: "상세형" 화면. 한 대상(센서/단면/현장)을 깊이 보여줌.
뼈대 = 헤더(식별+상태+액션) / 핵심 시각화(차트 or 도면) / 요약 KPI / 상세 테이블 / (우측 보조 패널).
빈 상태·부분데이터까지 설계. 위험은 상태 색으로 먼저 보이게.
색·간격·타이포는 온사이트 디자인 토큰만(임의값 금지). 시계열=라인, 비교=바.
표면(모달/페이지/도면캔버스)은 상황에 맞게: 목록서 빠른확인=모달, 깊은탐색=페이지, 공간=도면캔버스.
mda-onsite-ds-sync 규칙 적용 — 추출값은 기존 토큰에 매칭/스냅/신규추가, 하드코딩 금지.
```
