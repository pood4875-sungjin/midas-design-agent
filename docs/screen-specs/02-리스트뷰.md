# 화면 설명서 — 리스트뷰 (통합 프로젝트 관리)

> **화면 종류**: 목록형 (List) · 프로젝트 선택 전 / 서비스 홈
> **Figma**: https://www.figma.com/design/Dlwg17pNvKRubRoHP0bWVF/온사이트-제품-최종?node-id=5125-27750&m=dev

---

## 1. 언제 / 왜 쓰나
- 통합 프로젝트(여러 현장)를 **테이블(표)로** 관리하는 화면.
- 많은 현장을 **찾고·정렬하고·비교**할 때. 지도뷰가 "어디"라면, 리스트뷰는 "목록·수치".

## 2. 화면 뼈대 (위 → 아래)
- **전역 유틸바**: 날씨 · 위험 알림/사이렌 · 일반 알림 · 사용자 · 심플/디테일 토글
- **서비스 홈 GNB**: 지도뷰 · 리스트뷰 · 현장 요약 (현재 = 리스트뷰)
- **검색 / 필터 바**: 현장명 검색, 상태·지역 등 필터
- **테이블 (메인)**: 현장 목록. 한 행 = 한 현장.
  - 열 예: 현장명 · 위치 · 상태 · 핵심 계측값 · 갱신 시각
  - 행마다 상태 색 표시(badge 또는 행 강조)
- **페이지네이션**: 항목 많을 때 페이지 나눔

## 3. 규칙 (지켜야 할 것)
- **정렬 기본 = 위험순.** 위험한 현장이 위로.
- 위험/사이렌 행은 강조(상태 badge 색 + 필요 시 행 배경).
- 글자색·행 높이·간격·구분선은 **디자인 토큰만**. 임의값 ❌.
- 항목 20개 넘으면 페이지네이션.
- 심플/디테일 모드에 따라 행 높이·표시 정보량 달라짐(density 토큰 2벌).

## 4. 상태(status) 처리 — 온사이트 척추
| 상태 | 의미 | 토큰 |
|---|---|---|
| 안전/정상 | 문제 없음 | `--color-safe` (green) |
| 주의·경고 | 관찰 필요 | `--color-caution` (orange) |
| 위험 | 조치 필요 | `--color-danger` (red) |
| 사이렌 | 즉시 대응 | `--color-siren` (bright red) |
| 계측 초과 단계 | 1~3차 초과 | `--grad-exceed-1~3` (그라데이션) |
