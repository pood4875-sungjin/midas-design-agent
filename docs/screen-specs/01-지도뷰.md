# 화면 설명서 — 지도뷰 (통합 프로젝트 관리)

> **화면 종류**: 지도형 (Map) · 프로젝트 선택 전 / 서비스 홈
> **Figma**: https://www.figma.com/design/Dlwg17pNvKRubRoHP0bWVF/온사이트-제품-최종?node-id=5141-55643&m=dev

---

## 1. 언제 / 왜 쓰나
- 통합 프로젝트(여러 현장)를 한눈에 관리하는 화면.
- 지도 위에서 **어느 위치의 어느 현장이 위험한지**를 즉시 파악하는 게 목적.
- 공간(위치) 기반 모니터링 → 표보다 "어디"가 중요할 때.

## 2. 화면 뼈대 (위 → 아래)
- **전역 유틸바**: 날씨 · 위험 알림/사이렌 · 일반 알림 · 사용자 메뉴 · 심플/디테일 토글
- **서비스 홈 GNB**: 지도뷰 · 리스트뷰 · 현장 요약 (현재 = 지도뷰)
- **지도 (메인)**: 현장 위치마다 핀(마커)
- **현장 핀**: 상태 색으로 위험도 표시 (아래 4번)
- **사이드 패널**: 핀 선택 시 그 현장 요약(이름·상태·핵심 계측값·바로가기)

## 3. 규칙 (지켜야 할 것)
- **위험이 먼저 보여야 한다.** 위험/사이렌 현장은 지도에서 제일 눈에 띄게(크게·강조·깜빡임 가능).
- 핀 색·텍스트색·간격은 **디자인 토큰만** 사용. 임의 색 ❌.
- 핀 많으면 묶어서(클러스터) 표시, 확대하면 펼침.
- 사이렌(critical) 발생 시 전역 알림이 다른 것보다 우선.

## 4. 상태(status) 처리 — 온사이트 척추
| 상태 | 의미 | 토큰 |
|---|---|---|
| 안전/정상 | 문제 없음 | `--color-safe` (green) |
| 주의·경고 | 관찰 필요 | `--color-caution` (orange) |
| 위험 | 조치 필요 | `--color-danger` (red) |
| 사이렌 | 즉시 대응 | `--color-siren` (bright red) |
