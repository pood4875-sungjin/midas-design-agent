7월 1주차 주간 기록

6/30 ~ 7/4 · 기반 3갈래 착수 진행중
이번 주 — 각각 따로 굴린 3갈래. 온사이트 시스템화 · 정책 파이프라인(rulebook) · 한국 DS 테스트. 결국 "판단근거 파이프라인" 하나로 수렴.

한 일

  • 온사이트 → 시스템화 — 온사이트 제품을 디자인 시스템으로 정리. DESIGN-SYSTEM.md + 컴포넌트(GNB·버튼·드롭다운·아바타 등) + 토큰 정립. 실전 화면 5종(지도뷰·리스트뷰·현장요약·사이트뷰·멤버관리) 빌드. 파이프라인이 준수할 기준 DS.
  • 정책 / 판단근거 파이프라인 — PRD·시안 → DS 준수 화면을 "사람이 만든 것처럼" 생성하는 판단 기준서 rulebook 구축. 규칙 6종(IA·레이아웃·UX축7·컴포넌트·토큰·audit) + 패턴 카탈로그 2종(데이터표현 8·오버레이 5). 설계 문서화(생성정책 에이전트·디자인 인텔리전스 플로우).
  • 실전 검증 2빌드 — 같은 기능을 PRD추측(멤버관리 드로어)·Figma실측(초대 모달)로 각각 생성 → 소스 없이 추측하면 진입형태·상태표현이 빗나감 확인 → 소스별 판단 경계 규칙화.
  • 한국 기업 DS 탑재 테스트 — 한국 기업 DS를 가져와 탑재 후 별도 생성 테스트.
