# Node 6 — Audit ("사람이 만든 것처럼" 검증)

생성 결과가 DS·정책 준수 + 자연스러운지 최종 점검. 실패 항목 → gap → 게이트.

## 체크리스트

### 토큰 충실도
- [ ] 화면 CSS에 토큰화 가능 raw 값(font-size/weight/color/space/radius) 0. `grep -nE 'font-size:[0-9]+px' ... | grep -v var`
- [ ] 색은 EXACT(스냅 금지), 스케일값만 SNAP
- [ ] 신규 토큰/컴포넌트 → tokens.css + DESIGN-SYSTEM.md 갱신됨 (작업일자 흔적)

### 소스 충실도 (Figma 소스일 때)
- [ ] 진입형태·색·간격·상태표현 실측 일치
- [ ] 소스에 없는 variant/데이터 임의 생성 안 함

### 정책 준수
- [ ] 상태표현이 컨텍스트 규칙(R-5.3) 준수
- [ ] 권한 게이팅(R-4.3) 적용 — 금지 액션 비활성/숨김
- [ ] 파괴 액션 danger+확인모달(R-4.4)
- [ ] 부가상태(빈/로딩/에러) 정의됨(R-3.10)

### 자연스러움 (사람 판단 규칙)
- [ ] 액션 상시노출 아닌 hover/조건부(노이즈 억제)
- [ ] 파괴·소급 결과 사전 고지 문구
- [ ] progressive disclosure(고급값 접기)
- [ ] 동형 화면 패턴 재사용(학습비용)

### 렌더 검증
- [ ] preview 스크린샷 확인, 콘솔 에러 0
- [ ] (Figma 소스면) 시안과 나란히 대조

## 실패 처리
체크 실패 = gap. 규칙으로 고칠 수 있으면 자동, 새 판단 필요하면 제안→게이트.
